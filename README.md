# Fuga Espacial e Hoje

## Jogo: Fuga Espacial

Desvie dos meteoros usando as setas ou A/D no teclado. No celular, arraste o dedo para mover a nave. Você tem três vidas; o recorde fica salvo no navegador.

Execute `npm start` e abra `http://localhost:3000/`. O jogo é estático e pode ser publicado no GitHub Pages.

## Aplicativo de tarefas: Hoje

Um aplicativo simples de tarefas em português. Permite criar, concluir, filtrar e remover tarefas; os dados são salvos no navegador com `localStorage`.

## Executar

Requer Node.js 20 ou superior. Não há dependências para instalar.

```sh
npm start
```

Abra `http://localhost:3000/tarefas.html`. Para usar outra porta, defina `PORT` antes de iniciar.

No ambiente em nuvem, o comando completo é `cd /workspace/lucas && npm start`.

## Testar

```sh
npm test
```
