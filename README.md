# Hoje

Um aplicativo simples de tarefas em português. Permite criar, concluir, filtrar e remover tarefas; os dados são salvos no navegador com `localStorage`.

## Executar

Requer Node.js 20 ou superior. Não há dependências para instalar.

```sh
npm start
```

Abra `http://localhost:3000`. Para usar outra porta, defina `PORT` antes de iniciar.

No ambiente em nuvem, o comando completo é `cd /workspace/lucas && npm start`.

## Testar

```sh
npm test
```
